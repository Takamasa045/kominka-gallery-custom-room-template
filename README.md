# みんなの古民家ギャラリー｜丸ごと特注アトリエ見本

このフォルダは、**自分の扉の中を丸ごと自由な世界に作り変える「丸ごと特注アトリエ」** のための見本一式です。
はじめから **「星降る和紙灯りのアトリエ」**（マウスやスマホの指操作で夜空と浮かぶ額縁を眺められる展示室）が入っているので、今すぐギャラリーで試せます。

**非公開（Private）でも公開（Public）でも OK！** 会員サイトの **「GitHubとつなぐ」** でお部屋フォルダを 1 つ選んでおけば、鍵の設定なしで GitHub に保存するだけで自動反映できます（もちろん手元から `index.html` や `room.zip` を選んで試すこともできます）。

---

## かんたん 3 ステップ（GitHub から自動反映）

### 1. 自分の GitHub にコピーして、AI 相棒で開く（最初の 1 回だけ）
1. 右上の **「Use this template」→「Create a new repository」** を押して自分のお部屋フォルダを作ります（**Private（非公開）でも Public（公開）でも OK**）。
2. 会員サイトの **「お部屋を編集」→「GitHub連携」** タブで **「GitHubとつなぐ」** を押し、作ったお部屋フォルダを 1 つ選びます（見るだけ専用・書き換え不可・いつでも解除 OK）。もちろん公開フォルダのまま URL を貼る使い方もできます。
3. このフォルダを **Antigravity / Codex / Claude Code** で開きます（AI 相棒向けのルール `AGENTS.md` / `CLAUDE.md` が最初から入っています）。

### 2. 日本語で好きな世界を作ってもらい、GitHub に保存する
たとえば、こんなふうに話しかけるだけで丸ごと作り変えてくれます。

- **星空の部屋をベースにアレンジ**
  > 星空と浮かぶ額縁のギャラリーをベースに、作品タイトルを自分の4作品へ変えて、もう少しあたたかい夕暮れ寄りの空にして、GitHub に保存して。
- **まったく別の世界にする**
  > 森の中の小さな書斎みたいな展示室にして。本棚の本をクリックすると自分のエッセイが開くように作って、GitHub に保存して。
- **手元からアップロードして試したいとき（任意）**
  > スマホでも見やすいか確認して、12MB 以内の `index.html` と `room.json` をまとめた `room.zip` を作って。

### 3. ギャラリーで確認＆飾る
- **GitHub とつないでいる場合**：AI 相棒が `index.html`（と `room.json`）を GitHub に保存すると、部屋を開いたとき（または **「GitHub更新」** ボタン 1 押し）に自動で最新が反映されます。
- **手元のファイルから試す場合**：会員サイトの **「お部屋を編集」→「丸ごと特注アトリエ」** タブで `index.html` または `room.zip` を選び、**「自分だけの試着室で下見する」** で動きを確認 → 気に入ったら **「この特注アトリエを自分の扉に飾る」** を押します。
- ※いつでも **「古民家テンプレートに戻す」** で元の古民家のお部屋へワンクリックで戻せます。

> ⚠️ **大事なルール**
> 重い動画や大切な写真、個人情報・秘密情報（パスワード・本名・住所・連絡先など）は **GitHub にも `index.html` にも置かないでください**。

## このフォルダの中身

| ファイル | 役割 |
| --- | --- |
| `index.html` | これ 1 つだけで動く特注アトリエ本体（まずはそのままギャラリーで試せます） |
| `room.json` | 部屋の名前・作者名・作品名一覧のメモ（検索や案内にも使われます） |
| `AGENTS.md` / `CLAUDE.md` | AI 相棒が安全で軽いお部屋を作るためのルールブック |
| `README.md` | いま読んでいる使い方ガイド |

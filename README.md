# みんなの古民家ギャラリー｜丸ごと特注アトリエ見本

このフォルダは、**自分の扉の中を丸ごと自由な世界に作り変える「丸ごと特注アトリエ」**のための見本一式です。
はじめから **「星降る和紙灯りのアトリエ」**（マウスやスマホの指操作で夜空と浮かぶ額縁を眺められる展示室）が入っているので、今すぐギャラリーで試せます。

---

## かんたん3ステップ

### 1. このフォルダを AI相棒で開く
Antigravity / Codex / Claude Code でこのフォルダを開きます。
AI相棒向けのルール（`AGENTS.md` / `CLAUDE.md`）が入っているので、むずかしい設定なしで日本語のまま頼めます。

### 2. 日本語で好きな世界を作ってもらう
たとえば、こんなふうに話しかけるだけで丸ごと作り変えてくれます。

- **星空の部屋をベースにアレンジ**
  > 星空と浮かぶ額縁のギャラリーをベースに、作品タイトルを自分の4作品へ変えて、もう少しあたたかい夕暮れ寄りの空にして。
- **まったく別の世界にする**
  > 森の中の小さな書斎みたいな展示室にして。本棚の本をクリックすると自分のエッセイが開くように作って。
- **提出前の確認＆ZIPづくり**
  > スマホでも見やすいか確認して、12MB以内の `index.html` と `room.json` をまとめた `room.zip` を作って。

### 3. ギャラリーの「丸ごと特注アトリエ」タブで試着＆飾る
1. みんなの古民家ギャラリーで自分の部屋の **「お部屋を編集」** → **「丸ごと特注アトリエ」** タブを開きます。
2. **「index.html または room.zip を選ぶ」** を押して、このフォルダの `index.html`（または作った `room.zip`）を選びます。
3. **「自分だけの試着室で下見する」** で動きを確認します（この段階ではまだ誰にも見えません）。
4. 気に入ったら **「この特注アトリエを自分の扉に飾る」** を押せば、同じ自分の扉のまま特注アトリエが開きます！
   - ※いつでも **「古民家テンプレートに戻す」** で元の古民家のお部屋へワンクリックで戻せます。

## このフォルダの中身

| ファイル | 役割 |
| --- | --- |
| `index.html` | これ1つだけで動く特注アトリエ本体（まずはそのままギャラリーで読み込んで試せます） |
| `room.json` | 部屋の名前・作者名・作品名一覧のメモ（`room.zip` に一緒に入れると検索にも載ります） |
| `AGENTS.md` / `CLAUDE.md` | AI相棒が安全で軽いお部屋を作るためのルールブック |
| `README.md` | いま読んでいる使い方ガイド |
